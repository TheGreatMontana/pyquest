## Новая архитектура (кратко)

```
Домен ──► Карьерный путь ──► Стадии ──► Курсы (переиспользуемые)
                                          │  requires/grants
                                          ▼
                                     Навыки (граф пререквизитов)
Курс ──► Модули ──► Уроки ──► Блоки (11 типов)
                └─► Квиз, Задачи, Экзамен
```

Слои кода: `content.js` (ленивая загрузка) · `i18n.js` (языки) · `state.js` (прогресс и синхронизация) · `graph.js` (статусы и рекомендации) · `gamification.js` (XP) · `blocks.js` (интерактив) · `screens/*` (экраны).
