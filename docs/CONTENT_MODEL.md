# CONTENT_MODEL.md — модель контента и как его добавлять

Весь учебный контент — **данные в JSON**, не код. Ни одно изменение контента не требует правки JavaScript.

```
content/
├── catalog.json            домены, карьерные пути, курсы (метаданные), навыки, XP, ранги, достижения, роадмап
├── i18n/ui.<lang>.json     строки интерфейса (ru / uz / en)
├── courses/<id>.json       содержимое курса: модули → уроки → блоки, квиз, задачи, экзамены
├── courses/<id>.<lang>.json оверлей перевода курса (плоские пути → строка)
└── sql/store-db.sql        схема и данные учебной базы SQL-тренажёра
```

---

## 1. Мультиязычное поле

Любой видимый пользователю текст — объект:

```jsonc
"title": { "ru": "Списки", "uz": "Ro'yxatlar", "en": "Lists" }
```

Разрешение (`tr()` в `js/core/i18n.js`): текущий язык → `ru` → `en` → первое непустое.
Незаполненный перевод никогда не даёт пустой экран, а UI честно показывает плашку «перевод готовится».

**Не переводятся:** код (`code`, `starter`, `tests`, `solution`), идентификаторы, названия технологий.

## 2. Курс

```jsonc
{
  "id": "python-basics",
  "schema": 2,
  "modules": [ { …модуль… } ],
  "finalExam": { "time": 1800, "questions": [], "tasks": [] }   // необязательно
}
```

### Модуль
```jsonc
{
  "id": "pb-01",
  "legacyId": "m01",              // связь со старой версией — трогать нельзя, на ней держится миграция прогресса
  "title": {…}, "tagline": {…},
  "sqlModule": true,              // для SQL-курсов: подсветка и раннер переключаются на SQL
  "lessons": [ { "id": "l1", "title": {…}, "blocks": [ … ] } ],
  "quiz":  [ …вопросы… ],
  "tasks": [ …задачи… ],
  "exam":  { "time": 480, "questions": [ … ], "tasks": [ … ] }
}
```

## 3. Блоки урока

Урок — массив блоков. Разные типы дают разный ритм урока, поэтому уроки не выглядят одинаково.

| type | Обязательные поля | Что делает |
|---|---|---|
| `text` | `html` (ml) | Абзац или список, HTML разрешён |
| `code` | `code`, `lang` | Пример кода без запуска |
| `run` | `code` | Python-пример с кнопкой «Запустить» |
| `sqlrun` | `code` | SQL-пример, выполняется на учебной базе |
| `note` | `html` (ml), `kind`: `note`/`tip`/`trap` | Врезка: важно / совет / частая ошибка |
| `predict` | `code`, `options` (ml[]), `a`, `explain` | «Предскажи вывод», затем реальный запуск |
| `findbug` | `lines` (string[]), `bugLine`, `explain` | «Найди строку с ошибкой» |
| `match` | `pairs`: `[{left, right}]` (ml) | Сопоставление понятий и определений |
| `order` | `steps` (ml[]) — в правильном порядке | «Расставь шаги», порядок перемешивается при показе |
| `checkpoint` | `q` (ml), `options`, `a`, `explain` | Проверка знаний внутри урока |
| `summary` | `items` (ml[]) | Итоги урока |

Интерактивные блоки (`predict`, `findbug`, `match`, `order`, `checkpoint`) дают XP **один раз** — повтор не начисляет.

## 4. Вопрос квиза и экзамена

```jsonc
{
  "q": {…},                        // мультиязычный
  "code": "print(1)",              // необязательно
  "broken": true,                  // код намеренно содержит синтаксическую ошибку (не проверять компиляцией)
  "options": [ {…}, {…} ],         // мультиязычные варианты
  "a": 1,                          // индекс правильного
  "explain": {…}                   // обязателен для квиза, необязателен для экзамена
}
```

## 5. Задача

**Python:**
```jsonc
{
  "id": "t1", "kind": "python",
  "title": {…}, "brief": {…}, "desc": {…}, "hint": {…},
  "starter": "# стартовый код\n",
  "tests": "assert ... , 'понятное сообщение об ошибке'",
  "stdin": ["21"]                  // подставляется в input()
}
```
В тестах доступна переменная `_stdout` — весь вывод программы ученика. Сообщения ассертов — часть учебного опыта: пишите их как подсказку, а не как «AssertionError».

**SQL:**
```jsonc
{
  "id": "t1", "kind": "sql",
  "title": {…}, "desc": {…}, "hint": {…},
  "starter": "-- напиши запрос\n",
  "solution": "SELECT ...",        // эталон: результат ученика сравнивается с этим
  "checkQuery": "SELECT ...",      // если задача меняет данные — чем проверять результат
  "orderMatters": true             // учитывать порядок строк (для ORDER BY)
}
```

## 6. Как добавить

**Новый урок:** объект в `modules[].lessons[]` с массивом блоков.
**Новый модуль:** объект в `modules[]`, увеличить `moduleCount` курса в каталоге.
**Новый курс:** файл `content/courses/<id>.json` + запись в `catalog.courses` + ссылка из стадии пути.
**Новый домен:** запись в `catalog.domains` + карьерный путь в `catalog.careerPaths`.
**Новый пререквизит:** навык в `requires` курса; он должен быть в `grants` какого-то другого курса (валидатор это проверяет).
**Новый язык:** `content/i18n/ui.<lang>.json` + поля `<lang>` в контенте; недостающее подхватит fallback.

После любого изменения — прогнать проверки:

```bash
node tools/validate.js        # структура, ссылки, покрытие переводами
python tools/check-python.py  # компиляция и выполнение Python-фрагментов
node tools/check-sql.js       # выполнение SQL на реальном движке
python tools/check-tasks.py   # эталонные решения проходят автотесты
node tools/check-ui.mjs       # логика: миграция, граф, XP, языки
node tools/check-screens.mjs  # рендеринг всех экранов
node tools/check-mentor.mjs   # подсказки и разбор ошибок наставника
```
