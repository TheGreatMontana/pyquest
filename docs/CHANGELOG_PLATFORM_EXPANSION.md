## v2.4 — C, C++ и Java выполняются по-настоящему (2026-08-04)

В v2.3 компилируемые языки честно предупреждали, что кода не запускают. Теперь запускают — настоящими компиляторами, в браузере студента.

### Почему не на сервере

На сервере свободно **409 МБ RAM** из 3.7 ГБ, и там работают десять контейнеров чужого проекта. Компиляция C++ или запуск JVM забирают 300–500 МБ и уронили бы соседей по OOM. Публичный Piston API с февраля 2026 закрыт белыми списками. Поэтому всё считает браузер — как уже было с Python и SQL. Ассеты компиляторов отдаются статикой: диск дешёвый, память сервера не тратится вовсе.

### C и C++ — clang в браузере

- Настоящие **clang 8 и wasm-ld**, собранные в WebAssembly (проект binji/wasm-clang, Apache 2.0). Исходник компилируется в wasm-модуль и тут же исполняется.
- Работает: указатели, `malloc`/`free`, `string.h`, структуры, рекурсия; в C++ — `iostream`, `vector`, `string`, `map`, `set`, классы, наследование, виртуальные методы, `sstream`, `memory`, `cmath`, `algorithm`.
- В поставке sysroot не хватало softfloat-функций для `long double`, из-за чего `<algorithm>` не линковался. Раннер собирает недостающие символы отдельным объектом при первом запуске.
- Ассеты (58 МБ) — `runtime/wasm-clang`, в репозиторий не кладутся: `node tools/fetch-wasm.mjs`.

### Java — ecj под CheerpJ

- JVM даёт **CheerpJ 4.2**, компилятор — **ecj 3.21** (Eclipse Compiler for Java), лежит у нас.
- Дорога заняла три попытки: CheerpJ 3.0 роняет ecj внутренней ошибкой в фоновом потоке парсера, а ecj 3.33 не грузится вовсе — собран под Java 11, тогда как CheerpJ держит восьмёрку.
- Проверено: коллекции, `Arrays.sort`, ловушка `==` против `.equals()`, кириллица, диагностика ошибок компиляции, исключения времени выполнения.

### Что это дало курсам

- Задачи C, C++ и Java засчитываются **по реальному выводу программы** (поле `expected`), а не по самопроверке.
- Примеры в уроках стали запускаемыми: новые типы блоков `crun`, `cpprun`, `javarun`.
- Фрагмент без `main()` раннер оборачивает сам — в уроке можно показать три строки.

### Ошибки, которые поймали тесты

- `getFileContents` отдаёт view в память WASM: при её росте буфер отцеплялся, и вторая сборка подряд падала. Копируем байты.
- `addFile` обрезал каждый символ строки до одного байта — «Ю» (U+042E) превращалась в точку, «Л» — в ESC. Исходник кодируем в UTF-8, вывод декодируем обратно.
- Worker создаётся из `blob:`-URL, а относительные пути от него не резолвятся: `importScripts('wasm/shared.js')` падал. Ни один Node-тест этого увидеть не мог — отсюда следующий пункт.

### Тесты

- `tools/check-clang.mjs` — прогоняет C и C++ через тот же clang, что и браузер.
- `tools/check-java.mjs` — гоняет Java в headless Chrome, потому что JVM живёт только там.
- `tools/browser-check.mjs` — поднимает настоящий Chrome и проверяет раннеры на живом сайте: DevTools Protocol через встроенный в Node WebSocket, без puppeteer.
- Итого **13 наборов**, все зелёные.

### Остаётся

**C#** — единственный язык без рантайма в браузере. Реальный путь один: собрать Blazor WebAssembly с Roslyn, для чего нужен .NET SDK (локально стоит только рантайм). Пока — сверка с эталонным решением, о чём интерфейс говорит прямо.

## v2.3 — Пять языков программирования (2026-08-04)

До этой версии платформа умела только Python и SQL. Теперь на ней можно учить пять языков, и каждый — честно: где код исполнить в браузере реально, он исполняется; где нет — так и написано.

### Добавлено

**Тренажёр JavaScript (`js/jsrunner.js`)**
- Код выполняется в **изолированном Web Worker**: нет доступа к DOM, к странице, к localStorage. Бесконечный цикл убивается по таймауту 5 секунд — вкладка не зависает.
- `console.log/error/warn/info` перехватываются, объекты и массивы печатаются как JSON.
- Автотесты задач получают те же помощники, что и Python-задачи: `assert(условие, сообщение)`, `equal(факт, ожидание)`, плюс `stdout` с выводом решения.
- Новый тип блока в уроках — `jsrun` (интерактивный JS прямо в теории).

**Курс JavaScript (`javascript-basics`)** — с настоящим выполнением
- 4 урока: переменные и `let/const`, функции и стрелки, массивы (`map/filter/reduce`), объекты и деструктуризация.
- 6 вопросов, 3 задачи с автотестами, экзамен. Все решения проверены тестом `check-js.mjs`.

**Курсы C, C++, C#, Java** — теория без вранья про исполнение
- `c-basics`: указатели, адреса, ручная память (`malloc`/`free`), почему C — фундамент под всем остальным.
- `cpp-basics`: классы, ссылки против указателей, RAII, контейнеры STL.
- `csharp-basics`: свойства, коллекции, LINQ — с прямой привязкой к уже изученному SQL (`Where`→`WHERE`, `Select`→`SELECT`).
- `java-basics`: JVM, коллекции, ловушка `==` против `.equals()`; отдельно объяснено, почему Spark, Kafka и Hadoop — JVM-инструменты, и зачем это Data Engineer.
- Компилируемые языки **не запускаются в браузере** — вместо кнопки «Запустить» в задаче стоит честная пометка и кнопка **«Сравнить с эталоном»**: пишешь своё решение, потом открываешь авторское и сравниваешь. Никакой имитации выполнения.
- Все 5 курсов **на трёх языках на 100%** (ru/uz/en).

**Подсветка синтаксиса пяти языков (`js/ui.js`)**
- Добавлена `hlCLike()` со своими наборами ключевых слов для JavaScript, C, C++, C#, Java. `codeBlock(code, lang)` сам выбирает подсветку: SQL → SQL, C-подобные → C-подобная, иначе Python.

**Каталог**
- Курсов стало 15, навыков 22, направлений 16, карьерных путей 7.
- Новые пути: **Frontend**, **Full-Stack**, **Software Engineering**.
- Направление Software Engineering переведено в статус «полное».

### Исправлено
- Валидатор компилировал как Python **любой** код из блоков `predict` и вопросов — включая JS, C и Java. Теперь код маршрутизируется по языку: Python компилируется и исполняется, JavaScript проверяется на разбор, компилируемые языки пропускаются. Это ловило 4 ложных ошибки.

### Тесты
- Новый набор `tools/check-js.mjs`: прогоняет эталонные решения JS-задач через их же автотесты той же логикой, что и браузерный раннер. Задача, которую нельзя решить, теперь не пройдёт незамеченной.

## v2.0 — Платформа (2026-08-03)

Превращение курса Data Engineering в мультидоменную платформу с поддержкой трёх языков. Ветка `feature/platform-expansion`, база — `main @ 4813414`.

### Добавлено

**Архитектура платформы**
- Модель «домены → карьерные пути → переиспользуемые курсы → модули → уроки → блоки».
- Граф навыков и пререквизитов с автоматическим вычислением статусов курсов.
- 16 IT-направлений: 1 полное (Data Engineering), 3 со стартовым контентом (Backend, Аналитика, Кибербезопасность), 12 с роадмапом и честной пометкой «в разработке».
- 9 курсов, из которых Python и SQL переиспользуются в 4 разных направлениях.

**Интернационализация**

### Изменено

- **Контент** переехал из исполняемых `data/*.js` в декларативные `content/**.json` — редактируется без риска сломать приложение.
- **Загрузка стала ленивой:** вместо 26 тегов `<script>` (219 КБ при старте) грузится каталог (~30 КБ), курс подтягивается при открытии. Старт стал заметно легче, особенно на мобильном.
- **`app.js` разбит** из монолита (~1000 строк) на модули: `core/` (i18n, content, state, graph, gamification) + `screens/` + `ui.js` + `blocks.js`.
- **XP-система** вынесена в конфиг, добавлена защита от повторного начисления за интерактивные блоки.
- **Дашборд** из витрины прогресса стал рабочим инструментом: диагностика слабых мест, навыки, рекомендация.
- **Доступность:** skip-link, видимые фокус-состояния, `prefers-reduced-motion`, статусы передаются текстом, а не только цветом, живые области для скринридеров.
- **Мобильная вёрстка** дополнена для новых экранов (граф пути, каталог, карточки курсов).
- **Ранги** дополнены восьмой ступенью «Инженер данных», достижений стало 15 (добавлены «Полиглот» и «Data Engineer»).

### Сохранено (ничего не удалено)

- Весь учебный контент первой версии: 99 уроков, 129 вопросов квизов, 60 задач, 21 экзамен — перенесены с автоматической проверкой на потери.
- Прогресс пользователей: мигрирован по карте `legacyMap`, исходные данные сохранены в `legacyMods` как страховка.
- Работающие подсистемы без изменений: Python-раннер (Pyodide), проверка задач через `assert`, API аккаунтов, синхронизация прогресса, сертификат.
- Роадмап ментора: те же идентификаторы пунктов — ранее поставленные галочки на месте.
- Старые `data/*.js` остались в репозитории и в бэкапе.

### Известные ограничения (честно)

- Переводы **интерфейса и заголовков** — 100% на трёх языках; **тексты теории** мигрированных курсов пока только на русском (для uz/en работает fallback с явной пометкой «перевод готовится»). Новые 3 курса переведены полностью.
- 12 из 16 направлений — это роадмап и структура без уроков, статус «в разработке» показан прямо на карточке.
- AI-наставник: подготовлена архитектура (абстракция провайдера), но живой функциональности нет — фейковых ответов не генерируем.
- XP считается на клиенте (см. `docs/SECURITY_NOTES.md`).
