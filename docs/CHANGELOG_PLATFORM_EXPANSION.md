# CHANGELOG_PLATFORM_EXPANSION.md

## v2.0 — Платформа (2026-08-03)

Превращение курса Data Engineering в мультидоменную платформу с поддержкой трёх языков. Ветка `feature/platform-expansion`, база — `main @ 4813414`.

### Добавлено

**Архитектура платформы**
- Модель «домены → карьерные пути → переиспользуемые курсы → модули → уроки → блоки».
- Граф навыков и пререквизитов с автоматическим вычислением статусов курсов.
- 16 IT-направлений: 1 полное (Data Engineering), 3 со стартовым контентом (Backend, Аналитика, Кибербезопасность), 12 с роадмапом и честной пометкой «в разработке».
- 9 курсов, из которых Python и SQL переиспользуются в 4 разных направлениях.

**Интернационализация**
- Три языка: русский, o'zbekcha, English. Переключатель в шапке, выбор запоминается.
- Словари интерфейса (~200 ключей × 3 языка), мультиязычные поля контента, fallback-цепочка `выбранный → ru → en`.
- Оверлеи переводов курсов — отдельные файлы, грузятся только для текущего языка.

**Интерактивные уроки**
- 11 типов блоков вместо сплошного текста: текст, код, запускаемый Python, запускаемый SQL, врезки (важно/совет/ловушка), «предскажи вывод», «найди баг», «сопоставь пары», «расставь по порядку», проверка знаний, итоги.

**Новые экраны**
- Каталог направлений и курсов.
- Страница направления с визуальным графом карьерного пути.
- Страница курса с навыками, пререквизитами и переиспользованием.
- Дашборд с диагностикой: статистика, слабые места, полученные навыки, рекомендация следующего шага.
- Практика — задачи из пройденных модулей вперемешку.
- Оценка уровня — 10 вопросов и рекомендация стартового модуля.

**Новый контент**
- 3 курса с нуля, полностью на трёх языках: «Бэкенд: введение» (HTTP, REST, JSON), «Аналитика данных: введение» (метрики, медиана, группировки), «Кибербезопасность: введение» (CIA, хеширование, SQL-инъекции).

**Инструменты и тесты (в репозитории, а не во временных папках)**
- `tools/migrate-content.js` — миграция контента с проверкой на потери.
- `tools/validate.js` — структура, ссылочная целостность, циклы в графе, покрытие переводами.
- `tools/check-python.py`, `tools/check-sql.js` — прогон всех фрагментов реальными движками.
- `tools/check-tasks.py` — эталонные решения проходят автотесты задач.
- `tools/check-ui.mjs`, `tools/check-screens.mjs` — миграция прогресса, граф, XP, рендеринг экранов.

**Документация**
- 9 документов в `docs/`: аудит, архитектура, миграция, модель контента, роадмап, XP, безопасность, деплой, финальный отчёт.

### Изменено

- **Контент** переехал из исполняемых `data/*.js` в декларативные `content/**.json` — редактируется без риска сломать приложение.
- **Загрузка стала ленивой:** вместо 26 тегов `<script>` (219 КБ при старте) грузится каталог (~30 КБ), курс подтягивается при открытии. Старт стал заметно легче, особенно на мобильном.
- **`app.js` разбит** из монолита (~1000 строк) на модули: `core/` (i18n, content, state, graph, gamification) + `screens/` + `ui.js` + `blocks.js`.
- **XP-система** вынесена в конфиг, добавлена защита от повторного начисления за интерактивные блоки.
- **Дашборд** из витрины прогресса стал рабочим инструментом: диагностика слабых мест, навыки, рекомендация.
- **Доступность:** skip-link, видимые фокус-состояния, `prefers-reduced-motion`, статусы передаются текстом, а не только цветом, живые области для скринридеров.
- **Мобильная вёрстка** дополнена для новых экранов (граф пути, каталог, карточки курсов).
- **Ранги** дополнены восьмой ступенью «Инженер данных», достижений стало 15 (добавлены «Полиглот» и «Data Engineer»).

### Сохранено (ничего не удалено)

- Весь учебный контент первой версии: 99 уроков, 129 вопросов квизов, 60 задач, 21 экзамен — перенесены с автоматической проверкой на потери.
- Прогресс пользователей: мигрирован по карте `legacyMap`, исходные данные сохранены в `legacyMods` как страховка.
- Работающие подсистемы без изменений: Python-раннер (Pyodide), проверка задач через `assert`, API аккаунтов, синхронизация прогресса, сертификат.
- Роадмап ментора: те же идентификаторы пунктов — ранее поставленные галочки на месте.
- Старые `data/*.js` остались в репозитории и в бэкапе.

### Известные ограничения (честно)

- Переводы **интерфейса и заголовков** — 100% на трёх языках; **тексты теории** мигрированных курсов пока только на русском (для uz/en работает fallback с явной пометкой «перевод готовится»). Новые 3 курса переведены полностью.
- 12 из 16 направлений — это роадмап и структура без уроков, статус «в разработке» показан прямо на карточке.
- AI-наставник: подготовлена архитектура (абстракция провайдера), но живой функциональности нет — фейковых ответов не генерируем.
- XP считается на клиенте (см. `docs/SECURITY_NOTES.md`).
