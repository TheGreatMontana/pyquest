
## Глубина: вторые модули для всех коротких курсов

Курсов с единственным модулем больше нет. Тринадцать курсов получили
продолжение — не обзор терминов, а рабочий уровень с настоящими ловушками.

| Курс | Второй модуль |
|---|---|
| ml-intro | k-NN, матрица ошибок, precision и recall, нормализация, утечка данных |
| dl-intro | численная производная, скорость обучения, эпохи, расхождение и nan |
| nlp-intro | стоп-слова, TF-IDF, наивный Байес со сглаживанием, дисбаланс классов |
| cv-intro | пулинг, гистограмма яркости, поиск по шаблону и его хрупкость |
| devops-intro | канареечный релиз, логи против метрик, перцентили, бюджет простоя |
| bigdata-intro | колоночные форматы, партиционирование, сжатие, мелкие файлы |
| cloud-intro | статьи счёта, автомасштаб с потолком, зоны и честный расчёт отказа |
| infosec-intro | журналы без секретов, обнаружение, два фактора, фишинг |
| backend-intro | валидация, авторизация на каждом запросе, пагинация, идемпотентность |
| analytics-intro | воронка и узкое место, когорты, парадокс Симпсона, корреляция |
| security-intro | XSS, CSRF, забытая проверка прав, открытое перенаправление |
| csharp-basics | List и Dictionary, свои обобщения, конкретный catch, record |
| tailwind-basics | grid и flex, состояния, тёмная тема, компонент против @apply |

Было: 49 модулей, 189 уроков, 198 задач.
Стало: **62 модуля, 228 уроков, 248 задач, 640 вопросов, 62 экзамена.**

Всё проверено теми же инструментами, что и раньше: примеры выполняются,
у каждой задачи есть эталонное решение, C# собирается настоящим Roslyn,
вёрстка проверяется по вычисленным стилям в браузере.

### Найдено по дороге

- `append-module.mjs` заменял текст строкой, а в строке замены `$$` значит
  один доллар — хелпер `$$` в тестах по вёрстке молча превращался в `$`.
  Тесты при этом «проходили» с `undefined`. Замена теперь функцией.
- `predict`-блок на C# без поля `lang` уходил в проверку Python-фрагментов.

### Новые инструменты

- `tools/append-module.mjs` — дописывает модуль в курс, не переформатируя файл
- `tools/sync-catalog.mjs` — подтягивает `moduleCount` и часы в каталоге
