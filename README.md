# PyQuest — интерактивная платформа обучения IT

Учись программированию по-настоящему. **Python, JavaScript, SQL, C, C++ и Java выполняются прямо в браузере** — настоящими компиляторами и рантаймами, без отправки кода на сервер. Задачи проверяются автоматически, экзамены с таймером открывают следующие модули. C# пока идёт со сверкой по эталонному решению, и платформа честно об этом пишет. Три языка интерфейса: **Русский · O'zbekcha · English**.

**Живая версия:** https://course.azizbek-azimov.uz

---

## Что внутри

**16 IT-направлений** — от Data Engineering до DevOps. Курсы **переиспользуются**: пройденный Python засчитывается и в бэкенде, и в аналитике, и в кибербезопасности.

| Направление | Что внутри |
|---|---|
| Data Engineering | полный путь: Python → SQL → алгоритмы → инструменты DE |
| Frontend, Full-Stack | HTML, CSS, Tailwind, JavaScript — вёрстка рендерится живьём |
| Software Engineering | алгоритмы, структуры данных, инженерная дисциплина |
| AI, ML, Deep Learning, NLP, Computer Vision | модель, потери, нейрон, токены, свёртка — всё на живом Python |
| Backend, Аналитика, Кибербезопасность, ИБ | HTTP и REST, метрики, хеши и инъекции, риски и права доступа |
| Big Data, Cloud, DevOps | map-reduce и перекос, аренда и масштаб, конвейер и откат |

У каждого направления есть свой рассказ: что это за работа, зачем её учить и чему конкретно тут научишься.

**26 курсов · 49 модулей · 189 уроков · 198 задач · 50 экзаменов · 5 проектов · 16 направлений**

### Возможности

- **Шесть языков выполняются в браузере**: Python ([Pyodide](https://pyodide.org)), JavaScript (Web Worker), C и C++ (настоящий clang в WebAssembly), Java (ecj + [CheerpJ](https://cheerpj.com)), SQL ([sql.js](https://sql.js.org))
- **Живой предпросмотр вёрстки** — HTML, CSS и Tailwind рендерятся в sandbox-iframe, задачи проверяются по вычисленным стилям
- **14 типов блоков урока**: теория, запускаемые примеры, «предскажи вывод», «найди баг», «сопоставь пары», «расставь по порядку», проверка знаний, итоги
- **Граф пререквизитов**: курсы связаны через навыки, платформа подсказывает, чего не хватает и где это получить
- **Режимы**: карьерный путь целиком, отдельный навык, оценка уровня (с какого модуля начать), практика вперемешку
- **Аккаунты** с серверной синхронизацией прогресса — учись с любого устройства
- **Геймификация**: XP, 8 рангов, 15 достижений, ежедневный стрик — без накрутки повторами
- **Разбор ошибок** после каждого экзамена, именной сертификат по завершении курса
- Мобильная вёрстка, доступность (клавиатура, фокус, скринридеры, `prefers-reduced-motion`)

## Технологии

Чистые ES-модули без фреймворка и сборки — деплой обычным `scp`.

```
index.html              оболочка SPA, SVG-спрайт иконок
css/style.css           тёмная тема, дизайн-токены
js/
├── app.js              точка входа и роутер
├── core/
│   ├── i18n.js         языки, мультиязычные поля, fallback
│   ├── content.js      ленивая загрузка каталога и курсов
│   ├── state.js        прогресс, миграция схемы, синхронизация
│   ├── graph.js        навыки, пререквизиты, статусы, рекомендации
│   └── gamification.js XP, ранги, достижения
├── screens/            дашборд, каталог, курс, экзамен, роадмап, практика
├── blocks.js           интерактивные блоки уроков
├── runner.js           Python (Pyodide)
├── jsrunner.js         JavaScript (Web Worker, таймаут 5 с)
├── crunner.js          C и C++ (clang + wasm-ld в WebAssembly)
├── jrunner.js          Java (ecj под CheerpJ)
├── webrunner.js        HTML / CSS / Tailwind (sandbox-iframe)
└── sqlrunner.js        SQL (sql.js)
content/
├── catalog.json        домены, пути, курсы, навыки, XP, достижения
├── i18n/ui.*.json      интерфейс на ru / uz / en
├── courses/*.json      контент курсов (+ оверлеи переводов)
└── sql/store-db.sql    учебная база
server/app.py           API аккаунтов (Flask + SQLite)
tools/                  миграция и автотесты
docs/                   архитектура, миграция, безопасность, деплой
```

## Разработка

```bash
python -m http.server 8000        # ES-модули требуют http://, не file://
```

### Проверки перед деплоем

```bash
node tools/validate.js         # структура контента, ссылки, покрытие переводами
python tools/check-python.py   # Python-фрагменты компилируются и выполняются
node tools/check-sql.js        # SQL выполняется на реальном движке
node tools/check-js.mjs        # JS-фрагменты и задачи проходят свои автотесты
node tools/check-clang.mjs     # C и C++ собираются настоящим clang (нужен tools/fetch-wasm.mjs)
node tools/check-java.mjs      # Java собирается ecj и исполняется JVM в headless Chrome
node tools/browser-check.mjs   # раннеры проверяются в настоящем браузере на живом сайте
python tools/check-tasks.py    # каждая задача решаема эталонным решением
node tools/check-ui.mjs        # миграция прогресса, граф, XP, языки
node tools/check-screens.mjs   # все экраны рендерятся
node tools/check-mentor.mjs    # подсказки и разбор ошибок наставника
node tools/check-projects.mjs  # проекты, закладки, история
python tools/check-server.py   # серверная валидация прогресса
```

## Происхождение

Проект вырос из программы обучения, которую составил ментор автора: плейлист по Python, недельные задания по SQL Server (Week 1–4), «Грокаем алгоритмы», LeetCode и практика на реальных проектах. Эта программа целиком отражена в разделе «Роадмап» и в структуре курсов.
