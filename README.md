# PyQuest — путь Data Engineer

Интерактивная программа обучения по плану ментора: **Python → SQL (T-SQL) → Алгоритмы** + роадмап до первой работы. Никаких скучных лекций: тренажёры кода прямо в браузере, задачи с автопроверкой, экзамены с таймером, XP и достижения.

**Живой сайт:** https://course.azizbek-azimov.uz

## Три трека — 20 модулей

| Трек | Модули | Что внутри |
|---|---|---|
| **Python** | 10 | от установки до ООП и файлов — по плейлисту-первоисточнику |
| **SQL · T-SQL** | 6 | программа Week 1–4 ментора: SELECT, constraints, JOIN, GROUP BY, подзапросы, CTE, оконные функции |
| **Алгоритмы** | 4 | «Грокаем алгоритмы» гл. 1–6: сложность, бинарный поиск, сортировки, рекурсия, хеш-таблицы, BFS + мостик к LeetCode |

Плюс **Роадмап** — всё, что ментор расписал сверх сайта (Pandas, PySpark, Django+Docker, LeetCode 50+, английский), с чекбоксами и ссылками.

## Фишки

- **Python в браузере** — [Pyodide](https://pyodide.org) (CPython на WebAssembly)
- **SQL-тренажёр в браузере** — [sql.js](https://sql.js.org) (SQLite на WebAssembly) с учебной базой магазина; проверка сравнивает результат запроса с эталоном
- Каждый модуль: теория с запускаемыми примерами → квиз → задачи с автопроверкой → экзамен с таймером (70%+ открывает следующий модуль)
- Финальный экзамен Python-трека и именной сертификат (PNG)
- Геймификация: XP, 8 рангов (до «Data Engineer»), 13 достижений, ежедневный стрик
- План на 6 недель, привязанный к дате старта

## Технологии

Чистые HTML/CSS/JS без сборки. SVG-спрайт иконок, шрифты Inter + JetBrains Mono. Прогресс — в `localStorage`.

```
index.html       — оболочка SPA + SVG-спрайт
css/style.css    — тёмная тема
js/app.js        — роутер, треки, геймификация, квизы/задачи/экзамены, роадмап
js/runner.js     — Python-раннер (Pyodide)
js/sqlrunner.js  — SQL-раннер и проверка запросов (sql.js)
data/course.js   — треки, план, ранги, достижения, роадмап
data/sqldb.js    — учебная база SQL-тренажёра
data/m01–m10.js  — модули Python · data/s01–s06.js — SQL · data/a01–a04.js — алгоритмы
data/final.js    — финальный экзамен
deploy/          — конфиг nginx
```

## Запуск локально

```bash
python -m http.server 8000
# открой http://localhost:8000
```
