# 🐍 PyQuest — игровой курс Python

Интерактивная платформа для изучения Python с нуля за **14 дней**. Никаких скучных лекций — карта уровней, XP, ранги, стрики, ачивки, квизы, задачи с автопроверкой и экзамены-боссы.

**Живой сайт:** https://course.azizbek-azimov.uz

## Что внутри

- **10 модулей** по темам: установка → переменные → списки → циклы for → условия if → словари → циклы while → функции → ООП → файлы
- **Настоящий Python в браузере** — код выполняется через [Pyodide](https://pyodide.org) (CPython на WebAssembly), ничего устанавливать не нужно
- **Задачи с автопроверкой** — пишешь код, жмёшь «Проверить», тесты сразу говорят, что не так
- **Экзамены-боссы** с таймером после каждого модуля — сдал на 70%+, открыл следующий уровень
- **Финальный экзамен** по всему курсу и **именной сертификат** (PNG)
- **Геймификация**: XP, 7 рангов (от 🥚 Новичка до 🥷 Сенсея), 10 ачивок, ежедневный стрик 🔥
- **План на 14 дней** с календарём — что учить сегодня

## Технологии

Чистые HTML/CSS/JS без сборки и фреймворков + Pyodide с CDN. Прогресс хранится в `localStorage`.

```
index.html      — оболочка SPA
css/style.css   — тёмная игровая тема
js/app.js       — роутер, геймификация, квизы/задачи/экзамены
js/runner.js    — запуск Python-кода через Pyodide
data/course.js  — структура курса, план, ранги, ачивки
data/m01..m10.js— контент модулей (теория, квизы, задачи, экзамены)
data/final.js   — финальный экзамен
deploy/         — конфиг nginx
```

## Запуск локально

Любой статический сервер, например:

```bash
python -m http.server 8000
# открой http://localhost:8000
```

## Деплой

Статика лежит в `/var/www/course` на сервере, раздаётся nginx (см. `deploy/course.nginx.conf`), HTTPS — Let's Encrypt/certbot.

```bash
scp -r index.html css js data root@SERVER:/var/www/course/
```
